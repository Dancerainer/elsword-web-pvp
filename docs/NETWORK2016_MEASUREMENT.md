# Network measurement

Use a fixed build, preset, seed, asset manifest and input trace. Replay the same actor motion through each transport or codec under comparison. Record exact application bytes, reliable event delivery, acknowledgments, CPU and elapsed time. Distinguish compressed payload size from wire size and transport processing from full frame time.

Exercise idle, movement, attacks, persistent effects, packet loss, reordering and reconnection. Validate resulting actions, hits and the final actor state. A simulated clock measures ordering under its model. Measure end-to-end latency with real peers on the intended route and state the test conditions separately.
